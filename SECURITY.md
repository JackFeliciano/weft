# Security policy

## Reporting a vulnerability

Write to the repository owner through a private channel. The GitHub security advisory form on this repository reaches the owner without publishing the detail.

Do not open a public issue for a security defect, and do not include a working attack in a pull request.

## What this project holds

The project carries no credentials. Configuration that a deployment needs arrives through the environment, and the repository holds a sample file with the key names and empty values.

## Supported versions

The main branch is the supported version. Fixes land there first.
